# 🎮 Simon Says Game

A fun and interactive **Simon Says Memory Game** built using HTML, CSS, and JavaScript. The game challenges players to remember and repeat an increasingly long sequence of colours. With every successful round, the difficulty increases!

## 🚀 Features

- **Interactive Gameplay:** Start the game by pressing any keyboard key.
- **Random Sequence Generation:** A random coloured button flashes at every new level.
- **Level Progression:** Successfully repeat the sequence to move to the next level.
- **User Interaction:** Click the coloured buttons to reproduce the game sequence.
- **Instant Feedback:** Visual flashing effects indicate game and user button clicks.
- **Game Over Detection:** The game ends when an incorrect colour is selected.

## 🛠️ Tech Stack

- **HTML5** – Structure of the game.
- **CSS3** – Styling, layout and button animations.
- **JavaScript (Vanilla JS)** – Game logic, event handling, random sequence generation and DOM manipulation.

## 🎯 How to Play

1. Open the game in your browser.
2. Press any keyboard key to start the game.
3. Watch carefully as a coloured button flashes.
4. Click the same coloured button.
5. Remember the previous sequence as new colours are added.
6. Repeat the complete sequence correctly to reach the next level.
7. One wrong click and it's **Game Over!**
